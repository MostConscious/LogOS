# LogOS

Самодельная 32-битная операционная система, написанная с нуля на C и NASM.

## Что уже работает

- Загрузка в 32-битный режим (Protected Mode)
- Собственный драйвер видеокарты (VGA, белая тема)
- Прокрутка экрана (скроллинг)
- Драйвер клавиатуры (поддержка Shift для заглавных букв)
- Командная строка (Shell)
- Файловая система в оперативной памяти (RAM)
- Встроенный текстовый редактор (сохранение по Esc)

## Команды

- help - список команд
- clear - очистить экран
- ls - список файлов
- new <имя> - создать файл (например, new test.txt)
- cat <имя> - прочитать файл
- edit <имя> - открыть редактор
- AboutOS - информация о системе
- color white - включить белую тему

## Как собрать и запустить

Требования: nasm, gcc (с поддержкой 32-бит), ld, qemu-system-i386.

1. Сборка:
nasm -f elf32 heart.asm -o heart.o
gcc -m32 -c -ffreestanding -fno-pie -fno-pic -nostdlib lungs.c -o lungs.o
ld -m elf_i386 -T linker.ld -o LogOS.bin heart.o lungs.o

2. Запуск:
qemu-system-i386 -kernel LogOS.bin
